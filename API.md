# BarberShop API: опис для фронтенду

Це **договір** між бекендом і сайтом. Бекенд реалізується поетапно, але формат відповідей уже зафіксований, тому сторінку `booking.html` можна верстати зараз, підставивши тестові дані (мок) замість запитів.

Адреса під час розробки: `http://localhost:5000`. Усі відповіді в форматі JSON.

## Правила

- Графік роботи: **щодня 10:00 - 21:00** (як у футері сайту).
- Крок запису: **30 хвилин** (10:00, 10:30, 11:00 ...).
- Запис має **закінчитися до 21:00**: послуга на 60 хв не може починатися о 20:30.
- Дата завжди `YYYY-MM-DD` (наприклад `2026-11-05`), час `HH:MM` (наприклад `14:30`).
- Ціна залежить від **майстра**: у кожного барбера свій прайс на послуги.
- Категорії майстрів: `barber` (Барбер), `senior` (Старший барбер), `top` (Топ барбер).

## 1. Послуги

`GET /api/services`

```json
[
  {
    "id": 1,
    "title": "Чоловіча стрижка",
    "description": "Індивідуальний підбір форми ...",
    "duration": 45,
    "priceFrom": 500
  }
]
```

- `duration`: тривалість у хвилинах.
- `priceFrom`: найнижча ціна серед усіх майстрів. На картці послуги писати "від 500 грн".

## 2. Майстри

`GET /api/barbers`

```json
[
  {
    "id": 1,
    "name": "Олександр",
    "category": { "id": "senior", "name": "Старший барбер" },
    "experienceYears": 5,
    "description": "Досвід понад 5 років ...",
    "photo": "img/star_barber.jpeg",
    "services": [
      { "serviceId": 1, "price": 600 },
      { "serviceId": 2, "price": 400 }
    ]
  }
]
```

- `services`: що саме робить цей майстер і за яку ціну. Якщо послуги тут немає, майстра на неї обирати не можна.
- Фільтр: `GET /api/barbers?category=top`.

## 3. Вільний час майстра

`GET /api/barbers/:id/slots?date=2026-11-05&serviceId=1`

```json
{
  "date": "2026-11-05",
  "barberId": 1,
  "serviceId": 1,
  "slots": ["10:00", "10:30", "11:30", "14:00"]
}
```

- Повертає лише **вільні** початки запису з урахуванням тривалості послуги.
- Порожній масив `slots: []` означає, що вільного часу в цей день немає.
- Дата в минулому: помилка 400.

## 4. Створити запис

`POST /api/bookings`

Тіло запиту:
```json
{
  "clientName": "Іван",
  "phone": "+380991112233",
  "serviceId": 1,
  "barberId": 1,
  "date": "2026-11-05",
  "time": "14:00"
}
```

Успіх, `201 Created`:
```json
{
  "message": "Запис створено",
  "booking": {
    "code": "K7P3QX",
    "clientName": "Іван",
    "serviceTitle": "Чоловіча стрижка",
    "barberName": "Олександр",
    "date": "2026-11-05",
    "time": "14:00",
    "endTime": "14:45",
    "price": 600,
    "status": "active"
  }
}
```

**Код запису (`code`) треба показати клієнту** і запропонувати зберегти. Саме за ним та за телефоном він пізніше знайде й скасує запис. Сайт може також зберегти код у браузері (`localStorage`).

Помилки:

| Код | Коли |
|---|---|
| 400 | порожнє ім'я або телефон, неіснуюча послуга чи майстер, дата в минулому, майстер не робить цю послугу |
| 409 | цей час уже зайнятий (хтось встиг раніше), потрібно оновити список слотів |

Формат помилки: `{ "error": "Текст для показу клієнту" }`.

## 5. Переглянути свій запис

`GET /api/bookings/K7P3QX?phone=0991112233`

Телефон можна писати в будь-якому вигляді (`0991112233`, `+380991112233`, `099 111 22 33`). Код регістру не має значення.

Успіх, `200`:
```json
{
  "booking": {
    "code": "K7P3QX",
    "clientName": "Іван",
    "serviceTitle": "Чоловіча стрижка",
    "barberName": "Олександр",
    "date": "2026-11-05",
    "time": "14:00",
    "endTime": "14:45",
    "price": 600,
    "status": "active",
    "canCancel": true
  }
}
```

`canCancel` показує, чи можна ще скасувати запис: `true` лише для активного запису, до візиту якого лишилося **2 години або більше**. За цим полем сайт показує чи ховає кнопку "Скасувати".

Якщо код або телефон не збігаються (або телефон не передано): `404`. Відповідь навмисно однакова в усіх випадках, щоб не можна було вгадувати чужі коди.

## 6. Скасувати запис

`POST /api/bookings/K7P3QX/cancel`

Тіло:
```json
{ "phone": "0991112233" }
```

Успіх, `200`: `{ "message": "Запис скасовано", "booking": { ... "status": "cancelled", "canCancel": false } }`. Година знову стає вільною.

| Код | Коли |
|---|---|
| 404 | код і телефон не збігаються |
| 409 | запис уже скасований або візит минув |
| 422 | занадто пізно: до візиту менше 2 годин |

Усі помилки мають вигляд `{ "error": "Текст для показу клієнту" }`.

## Статуси запису

- `active`: запис діє.
- `cancelled`: скасований клієнтом.

Записи **не видаляються**, а лише змінюють статус.

## Статус реалізації

Усі розділи 1-6 реалізовані на бекенді.
